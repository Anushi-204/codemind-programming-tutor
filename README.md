# CodeMind – AI Powered Programming Tutor

## Overview

CodeMind is an AI-powered programming tutor web application that helps users learn programming concepts easily through AI-generated explanations, coding assistance, roadmap generation, and interactive learning support.
The platform is designed for beginners and students who want to improve their programming knowledge with a smart AI tutor experience.

- Groq API
